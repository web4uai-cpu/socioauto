# Content Strategy Skill

1. Load `brand.voice_guidelines` and current `trends`.
2. Balance goals: awareness, engagement, conversion — don't overweight one goal.
3. Assign each calendar entry: `{platform, topic, format, target_date, goal}`.
4. Respect platform cadence norms (e.g. don't over-schedule LinkedIn daily for a niche brand).
5. If `analytics_snapshots` from a prior cycle exist, prioritize topics/formats that performed best.
6. Output the calendar and hand off to `content-creation` per item.
